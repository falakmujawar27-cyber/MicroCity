Verification performed on download: HTTP 200 from source host, file size
confirmed on disk, JPEG magic bytes checked (`FF D8`), and each image was
visually inspected to confirm its subject matches its intended slot
(skyline → hero, campus courtyard → campus band, street intersection →
public band, aerial overpass → dashboard overview).

All four photographs are in the **public domain (CC0)** — no attribution is
legally required. Creator credits are given here and in on-page captions as
good practice. Wikimedia Commons was **not** used (persistent HTTP 429
rate-limiting); StockSnap CDN was rejected (403 on all fetches).

No other image files are bundled. All diagrams in the app are drawn
in-house as inline SVG React components.
